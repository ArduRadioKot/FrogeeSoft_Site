# FrogeeSoft

Статический сайт компании: `index.html`, каталог, команда и страницы программ. Сборка не требуется.

Версия FgSNotes и ссылки скачивания обновляются через GitHub Releases в `assets/downloads.js`. Ответ кешируется в браузере на час; если GitHub недоступен, используются последний сохранённый релиз или файлы из репозитория. Элементы с `data-release-version="fgsnotes"` получают одну и ту же актуальную версию на главной и на странице программы.

Общее оформление «FrogeeSoft | проект» и подписи авторов находятся в `assets/project-ui.css`. Авторы подписаны по исходникам и профилям проектов; для Яндекс Топологии и S.I.T Education использованы списки участников их репозиториев, для Sirius Wiki также сохранены отдельные авторы конспектов.
