FrogeeEngine

A lightweight, open-source game engine designed specifically for the CH32V003 portable game console

Download Engine View Documentation

Engine Features

Block-Based Architecture

Create games using an intuitive block-based system. Drag and drop components, connect them with visual scripting, and see your game come to life instantly.

Optimized Performance

Built specifically for the CH32V003 hardware, ensuring maximum performance and minimal resource usage. Perfect for creating smooth, responsive games.

Rich Asset Library

Access a comprehensive library of pre-made assets, including sprites, sounds, and animations. Easily import your own assets or create new ones.

Cross-Platform Support

Develop on Windows, macOS, or Linux. Export your games to multiple platforms while maintaining consistent performance and behavior.
