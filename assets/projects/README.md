# Проекты для компаний

- `geoscan-mops/result.webp`: снимок интерфейса МОПС из портфолио автора, исходник `cv/Alex-fgCV/assets/project-mops.webp`. Показана проверка поиска трещин на тестовых изображениях.
- `geoscan-mops/logo-*.svg`: логотипы из [репозитория МОПС](https://github.com/ArduRadioKot/Geoscan_MOPS/tree/main/frontend/src/assets).
- `uac-2026/atlant.png`: фотография платформы «Атлант» из [репозитория UAC_2026](https://github.com/nikitosrus01/UAC_2026/blob/main/assets/atlant_platform.jpg). В исходном репозитории файл с расширением `.jpg` содержит PNG.
- `uac-2026/navigation.svg`: навигационная пиктограмма для карточки проекта.

Описания и авторы сверены с README и участниками репозиториев [МОПС](https://github.com/ArduRadioKot/Geoscan_MOPS), [UAC_2026](https://github.com/nikitosrus01/UAC_2026) и [Яндекс Топологии](https://github.com/X200L/MarketLog). Поддержка компаний не обозначает наличие коммерческого контракта.
